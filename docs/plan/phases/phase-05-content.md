# المرحلة 5 — المحتوى

**الحالة:** ⬜ · **تعتمد على:** 3 · **نوعها:** محتوى وأدوات، ويمكن تنفيذها بالتوازي مع 4 و6

## الهدف
مكتبة برامج وتمارين موسّعة (الميزة الأساسية)، وروتينات تمدّد عامة لاستراحات التركيز، بصيغة واضحة ومترجمة
ومُتحقّق منها آليًا، مع خط إنتاج للصور.

## المدخلات
- حركة: `content-source/exercises.json` (50 تمرينًا)، و `estimates.json`، وبيانات البرامج والجرعات،
  و `IMAGE-HANDOFF-AR.md`، و `artwork/` (16 صورة).
- Orbit: مصفوفة `ROUTINE` في `index.html` (7 تمارين بالإنجليزي).

## المهام

### أ. صيغة المحتوى
- [ ] تصميم schema موحّد (JSON) يشمل:
  - **التمرين**: المعرّف، والاسم، والتحضير، والخطوات، والخطأ الشائع، والتلميح القصير، والأداة، ومناطق الجسم،
    ووضعية التنفيذ (واقف أو جالس أو أرضي)، وطريقة العدّ (مدة أو عدّات أو جهات)، والصورة، وحالة المراجعة.
  - **روتين الاستراحة**: تسلسل خطوات، والمدة الكلية، والمناطق المستهدفة، والنوع (قصير أو طويل).
  - **البرنامج**: الفئة، والمستويات، والجلسات، والمراحل، والمجموعات، والدورات، والاستراحات، والجرعات.
  - **بيانات الترشيح لكل برنامج ومستوى**: الأهداف (حركة، قوة، مرونة، هوائي)، والشدّة، ومدة الجلسة، والأيام المناسبة،
    والأدوات، وهل يحتاج نزولًا للأرض، ومناسبته للمبتدئين.
- [ ] النصوص بلغتين داخل نفس الملف أو بملفات منفصلة لكل لغة (يُقرّر)، مع `contentVersion`.
- [ ] كتابة `docs/CONTENT_GUIDE.md`.

### ب. النقل والدمج
- [ ] نقل تمارين حركة الخمسين مع الحفاظ على معرّفاتها كما هي.
- [ ] نقل تمارين Orbit السبعة، ودمج المكرّر منها مع حركة (مثلًا: المشي بالمكان، ولف الكتفين، والتفات الرقبة،
      وفتح الصدر).
- [ ] تصنيف كل تمرين حسب مناطق الجسم ووضعية التنفيذ، وهل يصلح كاستراحة عمل (بلا بساط، وبلباس العمل).
- [ ] تصميم روتينات استراحات التركيز: تمدّد عام بجانب المكتب (رقبة، وعيون، وأيدي ومعاصم، وكتفين، ومشي بالمكان)،
      قصيرة وطويلة، بلا بساط ولا أدوات.
- [ ] نقل البرامج الخمسة والخطط الـ45 كما هي، مع حالات اختبار تطابق الجرعات والترتيب (من `site/tests/vnext`).

### ب2. توسيع المكتبة
- [ ] اعتماد قائمة الفئات (تمدّد ومرونة، وبناء وقوة، وعام، وحركة، وهوائي، ومتنوّع) وتوزيع برامج حركة الحالية عليها.
- [ ] قرار عدد المستويات لكل برنامج (3 أو حتى 5)، وقواعد التدرّج بين المستويات (الجرعة، والصعوبة، والمدة).
- [ ] تحديد **الحد الأدنى للإطلاق**: عدد البرامج والمستويات الجاهزة يوم الإطلاق، وما ينزل لاحقًا كتحديث محتوى.
- [ ] كتابة البرامج والمستويات الجديدة، وإضافة التمارين التي تحتاجها إلى المكتبة.

### ج. الترجمة والتحرير
- [ ] ترجمة كل المحتوى إلى الإنجليزي (وتمارين Orbit إلى العربي) بنبرة `BRAND.md` والمسرد.
- [ ] مراجعة تحريرية للغتين.
- [ ] نص إرشادات السلامة العامة (الإرشادات الأربع في حركة) وإخلاء المسؤولية.

### د. أدوات التحقق
- [ ] سكربت في `tool/` يتحقق من: مطابقة الـ schema، وعدم تكرار المعرّفات، وصحة كل مرجع (برنامج ← تمرين،
      روتين ← تمرين)، واكتمال الترجمات، ووجود الصور المرجعية، وحساب المدد مقابل `estimates.json`.
- [ ] يعمل السكربت في CI.

### هـ. الصور
- [ ] **أسلوب رسوم التمارين (أول مهمة في المرحلة، قبل أي إنتاج صور):** نُقل من المرحلة 2 بقرار المستخدم (2026-10-23).
      الخيارات: خطّي، أو مسطّح، أو صور، أو أنيميشن (Rive أو Lottie)، مع نموذجين أو ثلاثة HTML بالوضعين،
      منسجمة مع الهوية المعتمدة في `docs/BRAND.md`، وتقييم صور `artwork/` من حركة مقابله.
- [ ] قائمة تسليم لكل التمارين (بالاستناد إلى `IMAGE-HANDOFF-AR.md`) بالأسلوب المعتمد.
- [ ] تقييم الصور الـ16 الموجودة، واعتماد الصالح منها أو استبداله.
- [ ] مواصفات التصدير: الأبعاد، والصيغة (WebP أو SVG أو Rive)، والوضعان الفاتح والغامق، وحجم أقصى للملف.
- [ ] الإنتاج قد يستمر بالتوازي حتى المرحلة 13، مع صورة بديلة مؤقتة لكل تمرين.

### و. المراجعة المتخصّصة
- [ ] التواصل مع أخصائي علاج فيزيائي لمراجعة التمارين والروتينات والجرعات (حالتها في حركة `pending`).
- [ ] تسجيل نتيجة المراجعة في المحتوى (حقل حالة المراجعة).

## المخرجات
`assets/content/` بمحتوى كامل بلغتين، و `docs/CONTENT_GUIDE.md`، وسكربت تحقق في CI، وقائمة إنتاج الصور.

- [ ] السكربت يمر بلا أخطاء على كل المحتوى.
- [ ] كل تمارين حركة الخمسين وتمارين Orbit السبعة منقولة ومصنّفة ومترجمة.
- [ ] روتينات استراحات التمدّد جاهزة (قصيرة وطويلة).
- [ ] برامج الحد الأدنى للإطلاق مكتملة، ولكل برنامج ومستوى بيانات ترشيح.
- [ ] تاريخ مراجعة الأخصائي محدد على الأقل (يمكن أن تكتمل لاحقًا، قبل المرحلة 14).
