# المرحلة 2 — بناء الهوية

**الحالة:** 🟡 (الهوية النصية مكتملة، والاتجاه البصري معتمد مبدئيًا) · **تعتمد على:** 1 · **نوعها:** تصميم ووثائق، بلا كود تطبيق

## الهدف
هوية بصرية ولفظية كاملة لـ **هِمّة (Himma)**، جاهزة لتتحوّل إلى نظام تصميم برمجي في المرحلة 4.

## المدخلات
- [`docs/BRAND.md`](../../BRAND.md): الهوية النصية المعتمدة، ومبادئ الهوية البصرية، وسجل الاستكشاف السابق.
- [`docs/PRODUCT.md`](../../PRODUCT.md): البرامج هي الميزة الأساسية، والمؤقت ميزة إضافية.
- مراجع قديمة (للاطلاع فقط): هوية Orbit (القرص والنقطة المدارية، وأنيميشن الإقلاع، وخطوط Outfit و IBM Plex)،
  وهوية حركة (8 لوحات ألوان في `site/js/data/palettes.mjs`، وخط Tajawal).

## ما تم
- [x] الاسم: هِمّة / Himma.
- [x] الشعار التعريفي: «ابدأ بحركة، واستمر بهِمّة.» / «Start Moving. Keep Going.»
- [x] العبارة الثانوية: «حركة صغيرة، أثر مستمر.»
- [x] مبادئ الهوية البصرية وما نتجنّبه.
- [x] جولة استكشاف أولى: 5 اتجاهات، وبرز منها Orbit Calm و Hybrid Concept، و4 تجارب ألوان. **كلها غير معتمدة.**

## المهام

### أ. استكمال الهوية النصية ✅
- [x] النسخة الإنجليزية للعبارة الثانوية: Small moves. Lasting impact.
- [x] كتابة الاسم: «هِمّة» بالتشكيل في الشعار، و«همة» في النصوص، و Himma بالإنجليزي.
- [x] الاسم في المتجر: «همة: عادات وتمارين يومية» / «Himma: Habits & Home Workouts».
- [x] أسماء الأقسام: اليوم، والبرامج، والعادات، والتركيز، والتقدّم.
- [x] لغة الكتابة: فصحى مبسّطة، وصيغة محايدة، وهادئة ومباشرة بلا إيموجي.
- [x] أمثلة «نقول / لا نقول» ومسرد المصطلحات (مع مصطلحات العادات): معتمدة في `docs/BRAND.md`.
- [ ] نصوص الإشعارات الكاملة: تُكتب مع المرحلة 10 بنفس القواعد.

### ب. جولة استكشاف بصري ثانية
- [ ] بحث مراجع خارج الاتجاهات السابقة: تطبيقات عافية وحركة وتركيز حديثة، بلا تقيّد بفكرة المدار.
      (لم يُنفَّذ بحث منفصل. الجولة الثانية بُنيت على 8 بطاقات اتجاهات في `brand/exploration/round-2/directions.html`)
- [x] 2 إلى 3 اتجاهات جديدة على الأقل، إضافة إلى تطوير Orbit Calm و Hybrid Concept.
- [x] لكل اتجاه: الفكرة، والشخصية، ولوحة مبدئية، وكيف يعبّر عن معنى «هِمّة» (المبادرة والاستمرار).

### ج. مقارنة عملية
- [ ] **شاشات متطابقة في الوظيفة والمحتوى** لكل اتجاه مرشّح، بالترتيب حسب أهميتها:
  1. «اليوم» (الشاشة الرئيسية).
  2. مشغّل جلسة البرنامج (أثناء تمرين).
  3. قائمة عادات اليوم وصفحة عادة (التقويم والإحصائيات).
  4. مكتبة البرامج أو صفحة برنامج.
  5. مؤقت التركيز.
  6. ويدجت واحدة على الأقل (العادات).
- [ ] أكثر من لوحة ألوان لكل اتجاه، بالوضعين الفاتح والغامق.
- [x] كل الشاشات بالعربي (RTL) أولًا، مع نسخة إنجليزية لشاشة واحدة على الأقل.
- [ ] معايير التقييم: الانسجام مع الاسم والشعار، والوضوح، والراحة البصرية، وخدمة البرامج قبل المؤقت،
      والتميّز عن المنافسين، وقابلية التنفيذ في Flutter.
- [x] الأداة: نماذج HTML بدل Figma (بموافقة المستخدم)، والمسارات في `docs/BRAND.md`.

### د. القرارات بالتسلسل
1. - [x] **الاتجاه البصري الرئيسي:** Orbit Calm مع لمسات Hybrid، معتمد مبدئيًا (2026-10-20). تطوير المدار والمحطات مع البند 5.
2. - [x] **لوحة الألوان** للوضعين (معتمدة 2026-10-20، القيم في `docs/BRAND.md` و`brand/tokens/colors.json`)، مع:
       - [x] ألوان دلالية (نجاح، تحذير، خطأ)، وتمييز لفئات البرامج إن لزم.
       - [x] فحص التباين بمعيار WCAG AA على الأقل، مع توثيق النسب.
       - [x] قرار: **لوحة واحدة** (2026-10-20).
       - [x] **لوحة ألوان العادات:** 10 إلى 12 لونًا يختار منها المستخدم، متناسقة مع الهوية وواضحة بالوضعين.
3. - [x] **الخطوط:** Rubik للعربية واللاتينية (معتمد 2026-10-20). أرقام المؤقت من Rubik نفسه بخاصية `tnum`.
       رخصة SIL OFL، تحققنا منها من بيانات Google Fonts. الخيارات التي قورنت: IBM Plex Sans Arabic، و Readex Pro، و Tajawal،
       و Noto Kufi Arabic، في `brand/exploration/round-2/fonts.html`.
4. - [ ] **الشعار والأيقونة:** رمز، وكلمة بالعربي وبالإنجليزي، ونسخة أحادية اللون. أيقونة Android adaptive
       و monochrome، و iOS (فاتح وغامق و tinted).
5. - [ ] **لغة الحركة والمؤقت:** مبادئ عامة (مدد ومنحنيات)، وشكل المؤقت، وأنيميشن الإقلاع،
       وبديل لتقليل الحركة.
6. - [ ] **توثيق نظام التصميم:** سُلّم الطباعة، والمسافات، والزوايا، والظلال، والأيقونات، والمكوّنات الأساسية.

### هـ. بنود مكمّلة
- [ ] **أسلوب رسوم التمارين** (مؤجّل قدر الإمكان بطلب المستخدم، مع أن إنتاج الصور في المرحلة 5 ينتظره): خطّي، أو مسطّح، أو صور، أو أنيميشن (Rive أو Lottie)، مع نموذجين أو ثلاثة،
      وتقييم صور `artwork/` من حركة مقابله. هذا القرار يحرّك إنتاج الصور في المرحلة 5، فيُفضّل حسمه مبكرًا.
- [ ] **أيقونات العادات:** مجموعة بنفس أسلوب أيقونات التطبيق (40 إلى 60 أيقونة: ماء، قراءة، نوم، مشي…)،
      مرسومة لهِمّة أو من مكتبة مفتوحة الرخصة.
- [ ] **الأصوات:** نهاية التركيز، وبداية الخطوة ونهايتها، ونهاية الجلسة؛ مع مراجعة أصوات حركة الستة.
- [ ] mockups لباقي الشاشات الأساسية بعد اعتماد الاتجاه: الإعدادات و onboarding وشاشة الترشيح.
