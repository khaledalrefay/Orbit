# المرحلة 2 — بناء الهوية

**الحالة:** ⬜ · **تعتمد على:** 1 · **نوعها:** تصميم ووثائق، بلا كود تطبيق

## الهدف
هوية بصرية ولفظية كاملة للتطبيق الموحّد، تكون جاهزة لتتحوّل إلى نظام تصميم برمجي في المرحلة 4.

## المدخلات
- `PRODUCT.md` والاسم المحسوم من المرحلة 1.
- هوية Orbit: القرص والنقطة المدارية، وأنيميشن الإقلاع، والأزرق `#2563EB`، وخطوط Outfit و IBM Plex.
- هوية حركة: 8 لوحات ألوان ثنائية (`site/js/data/palettes.mjs`)، وخط Tajawal، والأيقونة `dist/assets/icon.svg`.

## المهام

### أ. المفهوم
- [ ] الفكرة المركزية للهوية: كيف يجمع الشكل بين «المدار» (التركيز والدورات) و«الحركة» (الجسم).
- [ ] شخصية العلامة: 3 إلى 5 صفات (مثلًا: هادئ، عملي، دافئ، غير واعظ).

### ب. العناصر البصرية
- [ ] **الشعار**: رمز، وكلمة بالعربي، وكلمة بالإنجليزي، ونسخة أحادية اللون.
- [ ] **أيقونة التطبيق**: Android adaptive و monochrome (لـ Android 13+)، و iOS (فاتح وغامق و tinted).
- [ ] **الألوان**:
  - لون للتركيز ولون للحركة، ليظهر الانتقال بين الوضعين.
  - مقاييس محايدة للخلفيات والنصوص، بالوضعين الفاتح والغامق.
  - ألوان دلالية: نجاح، وتحذير، وخطأ.
  - التحقق من التباين بمعيار WCAG AA على الأقل، مع توثيق النسب.
  - قرار: هل نُبقي لوحات قابلة للاختيار مثل حركة؟ وكم عددها؟
- [ ] **الخطوط**: خط عربي وخط لاتيني متناسقان (المرشّح: IBM Plex Sans Arabic مع IBM Plex Sans، أو Tajawal)،
      وخط أرقام بعرض ثابت للمؤقت، والتحقق من الرخص (OFL).
- [ ] **سُلّم الطباعة** والمسافات ونصف قطر الزوايا والظلال.
- [ ] **الأيقونات**: مكتبة جاهزة (مثل Phosphor أو Lucide) أو مخصّصة، بسماكة خط موحّدة.
- [ ] **أسلوب رسوم التمارين**: خطّي، أو مسطّح، أو صور، أو أنيميشن (Rive أو Lottie)؛ مع نموذجين أو ثلاثة كتجربة،
      وتقييم صور `artwork/` من حركة مقابل هذا الأسلوب.
- [ ] **الحركة والأنيميشن**: مبادئ عامة (مدد ومنحنيات)، وأنيميشن الإقلاع، وبديل لتقليل الحركة.
- [ ] **الأصوات**: أصوات نهاية التركيز، وبداية الخطوة ونهايتها، ونهاية الاستراحة؛ مع مراجعة أصوات حركة الستة.

### ج. الهوية اللفظية
- [ ] **نبرة الكتابة** بالعربي والإنجليزي، مع أمثلة «نقول / لا نقول». المرجع: صوت شروحات Orbit.
- [ ] مسرد مصطلحات ثابت عربي-إنجليزي (تركيز، استراحة، جولة، جلسة، برنامج، مستوى، تعويض…).
- [ ] نصوص الإشعارات الأساسية بنفس النبرة.

### د. التطبيق على الشاشات
- [ ] Moodboard، ثم شاشات نموذجية (wireframe إلى mockup) لـ: يومك، والمؤقت، ومشغّل التمرين، والبرامج، والإعدادات.
- [ ] الأداة: Figma أو مكافئ، مع رابط في `BRAND.md`.

## المخرجات
- `BRAND.md`: كل ما سبق مع القيم الدقيقة (HEX، وأحجام الخطوط، والمسافات).
- مجلد `brand/`: ملفات الشعار والأيقونة بصيغة SVG و PNG، والخطوط ورخصها، ونماذج الرسوم.
- Design tokens بصيغة JSON، جاهزة لتحويلها إلى Dart في المرحلة 4.
